# PcapPlusPlus Tutorial - Writing a simple app

[Write a simple application](https://pcapplusplus.github.io/docs/tutorials/intro).

1. Install PcapPlusPlus.

2. Build using CMake from project root.

```shell
cmake -S 1-hello -B build/1-hello
cmake --build build/1-hello
```

3. Change to the `1-hello/` directory and run the executable:

```shell
cd 1-hello
./Tutorial-HelloWorld
```
