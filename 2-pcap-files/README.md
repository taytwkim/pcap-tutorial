# Read/Write Pcap Files

1. Install PcapPlusPlus.

2. Build using CMake from project root.

```shell
cmake -S 2-pcap-files -B build/2-pcap-files
cmake --build build/2-pcap-files
```

3. Change to the `2-pcap-files/` directory and run the executable:

```shell
cd 2-pcap-files
./Tutorial-PcapFiles
```
